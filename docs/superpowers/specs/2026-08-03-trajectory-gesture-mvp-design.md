# 空中轨迹手势 MVP 设计

## 范围

本轮只提供 App 前台内的“按住采集、松手结束”验证闭环：录制六轴 IMU 模板、DTW 识别、动作绑定、删除和通知反馈。不实现悬浮窗、后台轨迹激活、控灯、Webhook 或无障碍。

## 架构

- `SensorEngine` 保留现有 `MotionSample` 输出及背敲/摇动判据，只新增可选 `RawImuSample` 回调。加速度事件到达时输出去重力后的三轴线性加速度与最近一次三轴陀螺仪。
- `recognizer/trajectory` 是纯 Kotlin：数据模型、固定 48 点线性重采样、六轴逐维零均值/单位均方根归一化、带 Sakoe-Chiba 窗口的 DTW，以及最小距离加阈值识别。
- `TrajectoryGestureStore` 用独立 Preferences DataStore 保存 JSON。每个手势有稳定 ID、名称、多条原始模板、一个 `ActionId`；同名录制追加模板。
- `MainActivity` 在触摸按下时启动专用 `SensorEngine`，松开或取消时停止。录制模式弹名称框；识别模式读取快照、执行绑定动作并发通知。管理区动态显示动作下拉和删除按钮。
- 识别阈值进入 `AppSettings`，UI 可调，便于真机标定。

## 边界与错误处理

短于 8 个样本不保存/识别；无加速度计、传感器启动失败、空库、JSON 损坏、动作异常均转为中文提示或失败通知，不让交互闪退。陀螺仪缺失时三轴角速度为零。

## 测试

JVM 单元测试覆盖重采样端点与点数、归一化的零均值和尺度、相同形状在速度/力度变化后的低距离、不同形状的高距离、阈值命中与拒绝。最终运行全部单元测试和 debug 构建。
