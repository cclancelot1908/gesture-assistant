# Phase 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add shake recognition, persistent per-gesture action bindings, action executors, and configuration UI without changing the Phase 1 back-tap criteria.

**Architecture:** Both recognizers consume each normalized motion sample independently. `AppSettings` owns DataStore-backed detector and rule settings, `RuleEngine` resolves an immutable settings snapshot, and a composite executor routes actions to focused implementations.

**Tech Stack:** Android/Kotlin, Preferences DataStore, coroutines/Flow, JUnit 4, ViewBinding.
